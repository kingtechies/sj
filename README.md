# SJ Bot

A simple interactive bot for basic communication and interactions.

## Features

- Interactive command-line interface
- Time and uptime tracking
- Simple message processing
- Help system with available commands

## Usage

Run the bot using Python 3:

```bash
python3 bot.py
```

## Available Commands

- `hi/hello/hey`: Greet the bot
- `time`: Get current time
- `uptime`: Get bot uptime
- `help`: Show help message
- `quit/exit/bye`: Exit the bot

## Requirements

- Python 3.6 or higher

## Example Session

```
Hello! I'm SJ Bot. How can I help you today?
Type 'help' for available commands or 'quit' to exit.

SJ Bot> hi
Hello! I'm SJ Bot. How can I help you today?
SJ Bot> time
The current time is: 2025-10-24 11:39:00
SJ Bot> help
Available commands:
- hi/hello/hey: Greet the bot
- time: Get current time
- uptime: Get bot uptime
- help: Show this help message
- quit/exit/bye: Exit the bot
SJ Bot> quit
Goodbye! Have a great day!
```
